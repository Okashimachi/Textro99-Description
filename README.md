# Textro99-Description

「テキストロ99」（99人バトルロイヤル型タイピングゲーム）を、イベント出展会場でエンジニアの参加者向けに紹介する**説明サイト**。開発チーム「おかしまち」制作。

- ゲーム本体（[Textro99-WebFront](https://github.com/Okashimachi/Textro99-WebFront)）とは別リポジトリ。見た目のトンマナ（試合画面の「戦況コンソール」デザイン）だけを参考に作る、独立した静的サイト
- 「企画/仕様」「フロント」「バックエンド」の3ページで、各領域が頑張った点・意識した点を紹介する
- ルール・設計方針・ディレクトリ構造の詳細は **[AGENTS.md](./AGENTS.md)** を参照

## 画面構成

```
トップ
 ├─ 企画/仕様ページ
 ├─ フロントページ
 └─ バックエンドページ
```

トップは3枚のカードで分岐。共通ヘッダーに3ページ間の相互ナビと、テキストロ本体への「遊んでみる」導線を常設する。
